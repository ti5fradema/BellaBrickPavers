# Bella Brick Pavers

Marketing site for **Bella Brick Pavers** — paving / hardscape portfolio, equipment rental, online quote requests, and a full admin CMS.

## Features

- Public site: Home, Work mural (albums), Experience, Equipment rental, Quote form
- Admin (`/admin`): edit all copy, contact info, equipment, create/edit/delete work albums, upload photos, review quotes
- Brand colors: vivid yellow + charcoal gray
- Content stored in the browser (`localStorage`) with JSON export/import backup

## Admin

- URL: `/admin`
- Default password: `bella2026` (change under Admin → Settings)

## Local development

```bash
npm run dev
```
